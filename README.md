# Basic Browser Calculator

A simple, functional calculator built using **HTML**, **CSS**, and **JavaScript**. This project allows users to perform basic arithmetic operations through an interactive browser interface.

## Features

- Basic operations:  
  + Addition  
  - Subtraction  
  * Multiplication  
  / Division  
  % Modulus (Percentage)

- Functional buttons:  
    **AC** – Clears all input  
    **DEL** – Deletes the last character  
    **=** – Evaluates the entered expression

- Clean and responsive user interface
- No external libraries or frameworks used

## 📂 File Structure

├── index.html # HTML structure
├── style.css # Styling with CSS
└── script.js # Calculator functionality in JavaScript
